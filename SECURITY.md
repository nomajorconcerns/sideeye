# Security policy

This repo holds the SideEye website (the product is in development and not released).

## Reporting a problem

Please use GitHub's private vulnerability reporting: https://github.com/nomajorconcerns/sideeye/security/advisories/new

Do not open a public issue for a vulnerability. Include what you saw, how to reproduce it, and which page or file it affects.

## Scope

The website only: pages, scripts and build tooling in this repo. For the products themselves, see the Cephalo repo: https://github.com/nomajorconcerns/cephalo
